A proxy plugin runs inside an Orion proxy, the gateway players connect to before they reach the servers behind it. It uses `Orion.Proxy.Sdk`: the players of the network, the servers and groups, transfers between them, balancers that choose a server, Sentinel (the guard of the proxy) and maintenance.

<Badge text="Orion Proxy SDK 0.5" variant="note" />
