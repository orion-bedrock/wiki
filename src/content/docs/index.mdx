## Build your first plugin

The same four moves for a server or a proxy plugin, starting with the SDK.

<div class="home-sdk-note">
	<span class="home-sdk-badge" aria-hidden="true">SDK</span>
	<div>
		<strong>Get the SDK before you create the project.</strong>
		<p>The SDK is not public yet and is not on NuGet: clone the Orion repository and keep <code>Orion.Server.Sdk</code> or <code>Orion.Proxy.Sdk</code>, plus <code>Orion.Sdk.Generators</code>, next to your plugin. Without those project references, restore and build fail.</p>
	</div>
	<a class="home-sdk-link" href="sdk/">SDK overview <span aria-hidden="true">→</span></a>
</div>

<div class="home-tracks">
	<article class="home-track home-track-server">
		<header class="home-track-head">
			<span class="home-track-kicker">Server</span>
			<h3>Server plugin</h3>
			<p>Runs inside the game server and has access to worlds, players, blocks, items and entities.</p>
		</header>
		<ol class="home-track-steps">
			<li><span class="home-step-text"><strong>Get the SDK.</strong> Clone Orion and reference <code>Orion.Server.Sdk</code> and <code>Orion.Sdk.Generators</code>.</span></li>
			<li><span class="home-step-text"><strong>Create the project.</strong> A .NET 10 class library with <code>PublishAot</code>, <code>NativeLib</code> and unsafe code enabled.</span></li>
			<li><span class="home-step-text"><strong>Write the plugin.</strong> One <code>ServerPlugin</code>, one <code>[assembly: OrionPlugin]</code> and its <code>plugin.json</code>.</span></li>
			<li><span class="home-step-text"><strong>Publish and install.</strong> Put the native library in <code>plugins/&lt;id&gt;/native/&lt;rid&gt;/</code>.</span></li>
		</ol>
		<a class="home-track-link" href="server/plugins/basics/getting-started/">Open the server guide <span aria-hidden="true">→</span></a>
	</article>
	<article class="home-track home-track-proxy">
		<header class="home-track-head">
			<span class="home-track-kicker">Proxy</span>
			<h3>Proxy plugin</h3>
			<p>Runs in the gateway and handles players, servers, groups, transfers, balancers and Sentinel.</p>
		</header>
		<ol class="home-track-steps">
			<li><span class="home-step-text"><strong>Get the SDK.</strong> Clone Orion and reference <code>Orion.Proxy.Sdk</code> and <code>Orion.Sdk.Generators</code>.</span></li>
			<li><span class="home-step-text"><strong>Create the project.</strong> A .NET 10 class library with <code>PublishAot</code> and unsafe code enabled.</span></li>
			<li><span class="home-step-text"><strong>Write the plugin.</strong> One <code>ProxyPlugin</code>, <code>"application": "proxy"</code> and its <code>plugin.json</code>.</span></li>
			<li><span class="home-step-text"><strong>Publish and install.</strong> Put the native library in <code>plugins/&lt;id&gt;/native/&lt;rid&gt;/</code> next to <code>proxy.json</code>.</span></li>
		</ol>
		<a class="home-track-link" href="proxy/plugins/basics/getting-started/">Open the proxy guide <span aria-hidden="true">→</span></a>
	</article>
</div>

<div class="home-example">
	<div class="home-example-head">
		<div>
			<p class="home-eyebrow">A server plugin</p>
			<h3>One class is enough to start.</h3>
		</div>
		<p>The generator adds the entry point, <code>plugin.json</code> describes the plugin, and the SDK supplies <code>ServerPlugin</code>, commands and events.</p>
	</div>
	<div class="home-code">

```csharp title="ArenaPlugin.cs"
using Orion.Sdk;
using Orion.Sdk.Server;
using Orion.Sdk.Server.Events;

[assembly: OrionPlugin(typeof(Arena.ArenaPlugin))]

namespace Arena;

public sealed partial class ArenaPlugin : ServerPlugin
{
    public override void OnEnable() =>
        Context.Commands.Register("arena", spec => spec
            .Description("Where is the arena?")
            .Executes(call => call.Reply("The arena is at 0, 64, 0.")));

    [EventHandler]
    public void OnJoin(PlayerJoinEvent e) =>
        e.Player.SendMessage($"Welcome, {e.Player.Name}!");
}
```

	</div>
</div>
