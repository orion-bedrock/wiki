A server plugin runs inside an Orion server and uses `Orion.Server.Sdk`: the game, its worlds, players, blocks, items and entities, the events of the game, and the commands, tasks, forms and screens a plugin adds.

The vanilla identifiers of the game (`ItemIds.DiamondSword`, `BlockIds.Stone`, `EntityIds.Zombie`, `SoundIds`, `ParticleIds`, `EffectIds`, `EnchantmentIds`, `BiomeIds`, `PotionIds`) are constants of the namespace `Bedrock.Identifiers`, which the SDK brings with it. Wherever a page takes an identifier, a string such as `"minecraft:diamond_sword"` works too.
